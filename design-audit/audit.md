# Zoom98 Control 界面审查

## 审查依据

- `01-keymap-current.png`：改版前的实体键盘页面。
- `02-logitech-actions-reference.png`：用户提供的动作分类参考，仅参考信息架构，不复制视觉样式。

## 主要发现

1. 实体键盘布局已经能建立“屏幕键位—真实键帽”的对应关系，这是当前工具最清晰的部分。
2. 原改键弹窗把所有 VIA 键码平铺在一张技术清单里，普通用户难以判断媒体键、组合键、宏以及存储位置。
3. 全局“保存到键盘”按钮只对应灯光保存命令，却出现在所有页面，容易让用户误以为改键也需要再次保存。
4. BLE 页面展示所有附近广播、改名实验和完整通信日志，主任务被调试信息淹没。
5. 顶部修饰键说明与实体键盘内容重复，后续仍可进一步压缩，但本轮优先修复改键主流程。

## 本轮设计调整

- 改键弹窗按“普通按键 / 媒体与系统 / Mac 快捷键 / 自定义组合 / 文本宏”分组。
- 显示当前选择、十六进制键码和“保存在键盘，USB 与蓝牙均可用”的存储说明。
- 提供常用 Mac 快捷键预设，并允许由 Command、Option、Control、Shift 与普通键组成自定义单键组合。
- 将全局保存提示改为真实的持久化规则；灯光保存移动到灯光卡片。
- BLE 扫描结果仅保留 HID 键盘/鼠标与 Zoom98 Screen，日志折叠到诊断信息。

## 已知限制

- 自定义组合使用 QMK/VIA 的单键修饰键编码，适合 `Command + C`、`Command + Shift + 4` 等组合，不是带延时和多步骤的自动化。
- 文本宏沿用键盘固件现有的 ASCII 宏能力，不应保存密码等敏感内容。
- 自动化截图因当前 macOS 屏幕录制权限不可用而未能生成；编译、签名与应用打包已完成。
